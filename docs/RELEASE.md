ServiceHub 1.0.0: aplicação Java local para clientes, equipamentos, ordens de serviço, orçamento e estoque.

Baixe ServiceHub-1.0.0.zip, extraia e execute INICIAR.cmd no Windows com Java 17+ instalado. Abra http://localhost:8083. Consulte COMO-USAR.md dentro do pacote.

Inclui interface responsiva, dados fictícios, banco em arquivo, exportação CSV, testes de integração e de navegador. Uso local, sem autenticação. Não inclui Java no ZIP. SHA256SUMS.txt permite conferir a integridade do download.
